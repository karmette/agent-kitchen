# Evaluator

The `evaluator` module is designed to analyze and grade the effectiveness of a designated "Persuader" in a simulated conversation or discussion thread. It uses an AI judge (configured via your OpenAI-compatible API) to score the interaction based on a specific rubric.

## Components

The evaluation flow relies on several key files in this directory:

*   **`RUBRIC.md`**: Defines the grading criteria. By default, it evaluates the Persuader on four dimensions: Argument Strength & Logic, Empathy & Tone, Adaptability & Responsiveness, and Progress Towards Goal. Each is scored from 1 (Ineffective) to 5 (Exceptional). You can edit this file to customize the evaluation standards.
*   **`parse-db.py`**: A utility script used to extract a discussion thread from the backend database (SQLite/JSON) and format it into a readable HTML structure.
*   **`parse-db.json`**: A configuration file used by `parse-db.py` indicating which tables and columns to extract from the database to construct the discussion thread.
*   **`output.html`**: The HTML file generated by `parse-db.py`. It contains the complete transcript of the conversation (initial post and subsequent comments) that the AI will evaluate.
*   **`evaluate.py`**: The main execution script. It reads the contents of `RUBRIC.md` and the discussion thread (`output.html`), constructs a prompt, and queries the AI model. It then parses the AI's response and saves the output.
*   **`score.html`**: A full HTML report generated by the AI containing the detailed justification for each score, along with an overall summary.
*   **`score.json`**: A machine-readable JSON file containing only the numerical scores extracted from the AI's full response.

## Configuration & Setup

1.  **Environment Variables**: The evaluator uses the same `.env` file as the main backend. Ensure the following variables are set in your root or backend `.env` file:
    *   `OPENAI_API_BASE_URL`: The base URL for the API (e.g., `https://api.openai.com/`).
    *   `OPENAI_API_KEY`: Your API key.
    *   `MODEL`: The name of the model you wish to use as the judge (e.g., `gpt-4o`, `gpt-3.5-turbo`, or an open-source equivalent).

2.  **Dependencies**: The script requires `requests` and `python-dotenv`. Ensure they are installed in your environment (`pip install requests python-dotenv`).

## Usage

1.  **Generate the Discussion Thread**: First, ensure you have a conversation history exported cleanly to `output.html`.
    ```bash
    python parse-db.py
    ```
    *(Note: Depending on your setup, `parse-db.py` might require specific arguments or environment setup. Ensure `output.html` accurately reflects the conversation you want to grade).*

2.  **Run the Evaluator**: Execute `evaluate.py`. It will load the rubric and the HTML transcript, call the AI model, and generate the score files.
    ```bash
    python evaluate.py
    ```

3.  **Review the Results**: 
    *   Open `score.html` in a web browser to view the AI's detailed feedback and reasoning.
    *   Use `score.json` if you need to programmatically ingest the scores into another script or analytics dashboard.
